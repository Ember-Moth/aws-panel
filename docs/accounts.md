# 账号、代理与成员权限

面板区分三类身份：

- **成员**：登录面板的人，拥有团队角色和按 AWS 账号授予的权限。
- **AWS 账号**：资源所属的账号，以分区和 12 位账号 ID 唯一标识。
- **访问连接**：访问某个账号的方式，包括认证方式、区域和出口。一个账号可以有多条连接，更换凭据不会产生重复的账号记录。

## 接入 AWS 账号

管理员在“账号与代理”页操作：

1. **添加账号**：填写名称、分区和账号 ID，选择账号默认出口（直连或某个代理）。
2. **添加代理**（可选）：配置 SOCKS5 或 HTTP 代理的地址、端口和可选认证。
3. **添加连接**：展开账号，点击“添加连接”，选择认证方式和区域。新连接默认继承账号出口，也可以单独选择直连或其他代理。
4. **验证**：点击连接旁的“验证”。面板调用 STS `GetCallerIdentity`，检查账号 ID 与 ARN 分区是否一致；AssumeRole 连接要求来源连接已验证。
5. **授权成员**：在账号的“访问权限”中为成员授予 `read` 或 `operate`。

| 认证方式 | 输入与生命周期 |
| --- | --- |
| Access Key | Access Key ID 与 Secret Access Key；替换时完整提交 |
| 临时凭据 | 另加 Session Token 和到期时间（北京时间）；到期后需手工替换 |
| AssumeRole | 已验证的来源连接、目标 Role ARN、可选 External ID；会话一小时，提前一分钟自动刷新 |

角色链最多八层，拒绝循环和跨分区来源。跨账号 AssumeRole 需要目标角色的信任策略与来源身份的相应权限，参见 [AWS AssumeRole](https://docs.aws.amazon.com/STS/latest/APIReference/API_AssumeRole.html)。不支持 MFA 交互、SSO、会话策略和自定义 AWS endpoint。

账号列表中，账号状态汇总其连接：任一连接验证失败显示“验证失败”，有已验证连接显示“正常”，否则为“待验证”；停用的账号不会发起 AWS 请求。

身份验证只证明账号匹配和请求链路可用，不代表拥有资源操作权限，参见 [GetCallerIdentity](https://docs.aws.amazon.com/STS/latest/APIReference/API_GetCallerIdentity.html)。各功能所需权限见 [IAM 权限](iam.md)。

## 代理出口

- 每条连接持有独立的 HTTP Transport 和凭据缓存，不读取宿主机的 AWS 凭据或代理环境变量。
- SOCKS5 把目标域名交给代理解析；HTTP 代理使用 CONNECT，AWS TLS 证书仍由客户端校验，代理认证只用于代理握手。
- AssumeRole 请求与刷新使用目标连接的出口；角色链中每一层使用各自连接的出口。
- 代理故障、超时或认证失败时请求直接失败，**不会回退直连**，也不会改用其他代理。
- 代理检测请求固定的 AWS 公共 STS 地址，只验证网络和 TLS 链路，不发送 AWS 凭据。“已启用”表示本地配置状态，不代表检测成功。

验证结果区分配置、代理、网络、TLS、AWS 拒绝和账号不匹配，只显示稳定的错误分类，不显示原始错误中的密钥或代理密码。

修改凭据、代理、来源连接或账号默认出口会使相关连接需要重新验证；旧客户端不能继续使用旧配置，已经发出的请求可以结束。重新验证按“来源到目标”的顺序进行。

被账号或连接引用的代理不能删除，也不能原地切换协议；应先新建代理再切换绑定。被其他连接用作来源、或被未完成任务引用的连接同样不能删除。删除连接会删除面板中保存的秘密，不删除 AWS 资源。

## 成员与角色

| 能力 | 管理员 | 操作员 | 只读成员 |
| --- | --- | --- | --- |
| 概览、任务、个人设置、退出与改密 | 允许 | 允许 | 允许 |
| 成员管理、审计查询 | 允许 | — | — |
| 账号、连接、代理与授权管理 | 允许 | — | — |
| 账号与资源查询 | 全部账号 | 已授权账号 | 已授权账号 |
| 资源同步与配额查询 | 允许 | 需 read 授权 | 需 read 授权 |
| 创建、生命周期、地址、区域启用、Wavelength | 允许 | 需 operate 授权 | — |

- 只读成员即使获得 `operate` 授权也不能执行写操作。
- 普通成员只能看到授权账号的脱敏摘要，看不到连接配置与代理信息。授权角色链的目标账号不会授予来源账号的查询权限。
- 至少保留一个可用管理员，角色变更和禁用在数据库事务中串行检查。

## 登录与会话

- 第一个管理员通过 `admin init` 创建，此后成员由管理员添加。密码 15 至 128 个字符，以带独立随机盐的 Argon2id 存储。
- 会话令牌为 32 字节随机数，数据库只保存其 SHA-256；默认有效期 12 小时，重启后保持。退出撤销当前会话，改密撤销本人全部会话，禁用或调整角色撤销该成员全部会话。
- 登录按来源 IP 与用户名分别限流，默认 15 分钟内 60 次和 10 次；Redis 不可用时拒绝新登录。
- 所有写请求校验同源 Origin / Referer 与绑定会话的 CSRF token。JSON 客户端先 `GET /api/v1/auth/csrf`，携带 `X-CSRF-Token` 与 `Origin` 登录，此后使用响应中的会话 CSRF token。不接受 Bearer token 或 URL 中的会话值。

## 审计

成员、登录、账号、连接、代理、授权、任务提交 / 取消 / 恢复、定时同步和主密钥操作都写入审计，与业务修改在同一事务中提交。运行身份只能追加和读取审计，不能改写或删除。密码、会话、CSRF 值和凭据不会进入审计载荷。管理员可在“审计”页查询。
