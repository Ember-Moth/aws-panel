## 实现约束

沿用单进程模块化结构、账号与独立 SOCKS5 出口、默认关闭云端写入、预览/提交和租约保护。实例和地址属于多资源操作，需要同时锁定涉及的资源；发出请求前保存持久记录，响应不确定时先核对 AWS 状态。

Root 密码继续只保存加密哈希与绑定引用，不进入计划、任务或日志。IPv6 地址分配、网络准备和实际可达性分开呈现；未验证真实网络/SSH 的部分明确标注。

验收先使用本地模拟 AWS；实现功能不等同于授权创建未指定的真实计费资源。真实云端验证仍需要明确账号、区域与资源范围。

## 验证边界

本地已覆盖真实 AWS SDK/SigV4 + 独立 SOCKS5 + PostgreSQL/Redis、响应丢失与部分失败、多资源锁与租约、配额未知/不足、容量预留/BYOIP、密码秘密生命周期、快照失败保留、HTTP 权限与 CSRF，以及浏览器交互。原生预览保留已有数据，未创建 Linux 虚拟机。真实 AWS 创建/删除、SSH 密码登录、实际 IPv6 连通性及本次扩展的容器实跑尚未执行；云端写入仍关闭。详细说明见 [计算与地址管理](compute.md)。
