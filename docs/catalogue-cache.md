# 页面数据与创建目录缓存

选择账号与区域后，页面自动加载创建选项，不再要求每次点击查询 AWS。服务端把变化较慢的产品目录与账号状态分开缓存；首次访问没有快照时需要查询，后续命中直接返回。Redis 中的缓存可以跨应用重启复用，Redis 不可用时退回有界进程缓存和 AWS 读取。

| 数据 | 正常复用时间 | 过期快照最多保留 |
| --- | --- | --- |
| Lightsail 系统镜像、套餐及套餐价格 | 24 小时 | 7 天 |
| EC2 官方 AMI | 6 小时 | 24 小时 |
| EC2 / Wavelength 可售实例规格 | 24 小时 | 7 天 |
| 子网、路由、安全组、密钥、可用区和 Lightsail 配额快照 | 2 分钟 | 15 分钟 |
| 创建表单和区域管理共用的账号区域状态 | 10 分钟 | 1 小时 |
| 配额检测的应用上限（EC2、Lightsail、VPC、Bedrock） | 1 小时 | 24 小时 |
| 配额检测的资源用量 | 1 分钟 | 5 分钟 |
| EC2 实例列表、实例内的 IP/地址列表 | 30 秒 | 2 分钟 |
| Wavelength Zone 开通状态列表 | 2 分钟 | 15 分钟 |

正常复用时间过后，接口先返回仍在保留期内的快照，并启动一次后台刷新。刷新失败不覆盖已有快照，自动重试间隔至少一分钟；达到最长保留时间后必须读取成功，不能继续返回旧数据。后台任务随应用关闭取消。并发访问同一个目录共用刷新请求，避免重复分页查询。

页面显示更新时间、缓存和后台更新状态。“刷新最新”使用 `refresh=true`，等待 AWS 最新结果；读取失败会明确返回错误或未知字段，不把旧数据称为刷新成功。配额分页未完整成功的结果只供本次请求显示未知状态，不写入缓存，不覆盖先前成功的快照。表单中仍有效的选择和已填写内容保持不变。EC2 创建目录与实例列表独立返回，实例状态读取不会阻塞目录显示。后台更新的结果由下一次目录读取取得。

缓存按服务、账号、访问连接、连接配置指纹、区域和 Wavelength Zone 隔离。每次返回缓存前仍校验成员权限、账号/连接状态和临时凭据有效期；后台 AWS 请求沿用连接的授权及配置版本检查。连接、代理或凭据变更后使用新的缓存键。只缓存展示数据，不缓存凭据。内存和 Redis 各最多保留 128 个条目，每个序列化条目最多 512 KiB；Redis 缓存有独立命名空间和 TTL，不清理任务队列。

**创建预览与任务执行不使用展示缓存。** 它们仍直接向 AWS 校验镜像、规格、价格、网络、区域和配额。缓存中的镜像可能已下架、价格可能已变化；创建流程以新查询为准。生命周期操作、地址切换的预览/执行与配额校验仍读取最新 AWS 状态。实例和地址列表只缓存展示结果；刚创建的实例若未出现在地址列表缓存中，会自动再读取一次最新列表。区域启用任务自身不使用表单目录缓存。

不把套餐清单或 AMI ID 永久写死。Lightsail 会淘汰旧镜像，EC2 镜像可用性还受区域和账号策略影响。参见 [Lightsail 镜像说明](https://docs.aws.amazon.com/cli/latest/reference/lightsail/get-blueprints.html) 与 [EC2 DescribeImages](https://docs.aws.amazon.com/AWSEC2/latest/APIReference/API_DescribeImages.html)。

JSON 目录响应增加 `freshness`，每个部分提供 `updated_at`、`refresh_after`、`cached`、`stale`、`refreshing` 和 `refresh_failed`。目录、区域、实例、地址与配额接口支持可选 `refresh=true`；完整接口见生成的 Swagger。

## 其他页面的检查结果

| 页面 | 打开页面时的数据来源 | 处理 |
| --- | --- | --- |
| 仪表盘 / 账号池 | PostgreSQL 中的采集快照 | 已有本地快照；15 秒页面轮询不查询 AWS。明确提交的后台刷新任务继续重新采集。 |
| 资源快照、Lightsail 实例列表 | PostgreSQL 资源快照 | 保持已有手动/定时同步；浏览页面不重新访问 AWS。 |
| 任务、账号、代理、成员、审计、系统状态 | 本地数据库或运行状态 | 无需额外 AWS 数据缓存；显式连接验证仍重新验证身份与出口。 |
| 区域启用 | 与创建表单共用账号区域缓存 | 展示缓存与更新时间，手动刷新同时更新两个页面的数据源；计划与启用步骤实时检查。 |
| 配额检测 | 上限与用量分别缓存 | 切换页面或重复查看直接复用；用量过期不重新扫描上限。两类时间分别显示。 |
| EC2 / Wavelength 实例、实例内换 IP | 30 秒展示快照 | 显示状态读取时间，支持强制刷新；操作预览和执行不使用这些快照。 |

普通配额查询也显式采用每页最多 100 条，并继续按 NextToken 读取全部页面，减少首次加载的分页往返。冷查询与手动刷新允许最多两分钟；缓存命中不等待 AWS。上限依据 [ListServiceQuotas API](https://docs.aws.amazon.com/servicequotas/2019-06-24/apireference/API_ListServiceQuotas.html)，AWS 仍可能在单页返回更少数据。
