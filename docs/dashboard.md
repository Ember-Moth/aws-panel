# 概览

概览是登录后的首页，汇总当前成员可访问账号的资源、区域与配额，并列出需要处理的事项。同一个 AWS 账号添加多条连接不会重复计数。

## 页面内容

- **统计卡片**：AWS 账号、EC2 实例、Lightsail 实例、公网 IPv4、已启用区域。卡片底部标明数据时间；覆盖不完整时显示“部分数据”，快照过旧时显示“旧快照”。
- **需要处理**：没有已验证连接的账号、读取不完整的账号、用量达到 80% 的 EC2 / Lightsail vCPU 配额，以及服务端提示。每项带一个处理入口；没有事项时显示空状态。
- **账号池配额**：EC2 按需 vCPU 与 Lightsail vCPU 的已确认上限和用量，可展开查看 EC2 各实例类别。
- **账号状态**：每个账号的默认出口、采集所用连接、已启用区域数和采集状态。
- **Bedrock 模型配额**：可按模型、配额名称或代码筛选。

页头可以按账号和区域筛选。页面每 15 秒从数据库更新读数，不会因此请求 AWS。

## 刷新账号池

点击“刷新账号池”提交只读后台任务：

- 每个账号选用一条已验证连接，优先使用继承账号默认出口的连接。
- 先读取账号已启用的区域，结合 Lightsail 支持的区域，再逐区域读取资源和配额。
- 不受云端写入开关影响；不启用区域、不创建资源，也不调用 Bedrock 模型。
- 单个任务最多 50 个账号，超过后分批；单次最多 500 个账号，每个账号最多 80 个区域，单区域最多两路并发。无法提交的账号会列出原因。
- 每个账号独立保存进度，重启、消息重投或响应丢失都不会丢弃已完成的部分。

临时读取失败会保留旧读数。超过 15 分钟或最近一次采集失败时标记为旧快照。资源的定时同步结果也会被概览读取，见[实例](instances.md#同步)。

## 统计口径

| 指标 | 口径 |
| --- | --- |
| AWS 账号 | 当前成员可见的面板账号，另列启用数与可刷新数 |
| EC2 实例 | 最近成功快照中未终止的实例（含已停止），另列运行中数量 |
| Lightsail 实例 | 最近成功快照中的实例，另列运行中数量 |
| 公网 IPv4 | 实例地址、EC2 弹性 IP 与 Lightsail 静态 IP，按账号和区域去重；Carrier IP 单列，不含 IPv6 |
| 已启用区域 | 账号 × 区域的组合数，并列出不同区域数；只计 `ENABLED` 与 `ENABLED_BY_DEFAULT` |

未采集、无权限、分页不完整与真实的零分别处理：缺失部分显示为“—”或未知账号数，不当作零。停用的面板账号保留已知资源并标记旧快照，因为停用账号不等于删除云资源。

## 配额汇总

- 只统计启用账号及其已启用区域。
- EC2 主数值为已返回的按需类别 vCPU 合计，详情按标准、GPU、加速器等类别分别列出；类别之间的配额不能互换。
- Lightsail 汇总各区域的 vCPU 配额。
- 只有全部相关上限与用量都可确认且足够新时，才显示用量比例条。
- Bedrock 使用 Service Quotas 的账号级适用值，按配额代码、名称、单位、周期与全局标记分组，不混合不同模型、调用方式或 RPM / TPM / 每日 token 上限。全局配额每个账号只计一次。未返回的项目不视为零，也不用公开默认值代替。
- Bedrock 不读取实时消耗，不显示剩余额度。配额数值不代表模型访问权限或实际可用容量，参见 [Bedrock 运行时配额](https://docs.aws.amazon.com/bedrock/latest/userguide/quotas-runtime.html)。

单个账号、区域的详细配额与用量见左侧导航的“配额”页，说明见[实例](instances.md#配额)。

## 接口

- `GET /api/v1/dashboard`：支持 `account_id`、`region` 过滤。
- `POST /api/v1/dashboard/refresh`：`account_id`、`region` 可选，`idempotency_key` 必填；返回后台任务和未提交的账号。
